# Free texture repositories

Public GitHub repositories that give away Minecraft-style textures for others
to reuse, like [malcolmriley/unused-textures](https://github.com/malcolmriley/unused-textures).
They are hard to find because they are rarely tagged, so this list was put
together by searching GitHub, README and license wording, the people around
known texture repositories, and pages that link to them (October 2026).

Every repository below states permission to reuse: a license file, or a README
statement where noted. PNG counts are from the default branch, and no entry is
a fork or re-upload of another. Attribution-only licenses are included; read
each license before using the textures. "Browse" opens the repository in this
app.
